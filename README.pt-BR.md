## Sobre

Construo aplicações de IA generativa de ponta a ponta que conectam dados, recuperação de informação, orquestração de agentes e mecanismos de confiabilidade.

Meus projetos se concentram na camada de engenharia que demonstrações de IA frequentemente deixam de lado: guardrails determinísticos, avaliação automatizada, versionamento de prompts, rastreamento, critérios de qualidade integrados ao CI e observabilidade de custo e latência.

## Projetos em destaque

### [Sales Report AI](https://github.com/eduardo-ebdl/sales-report-ai) | LLMOps e Confiabilidade

Pipeline de LLM voltado a portfólio que gera relatórios executivos a partir de dados Gold no Databricks. Combina guardrails numéricos determinísticos, avaliação baseada em Claude, registry versionado de prompts com golden tests no CI e observabilidade em PostgreSQL para tokens, custo, latência, qualidade e drift de prompts.

**Stack principal:** n8n · Claude Haiku · Claude Sonnet · Databricks · PostgreSQL · FastAPI · GitHub Actions · Docker

### [Lupus](https://github.com/eduardo-ebdl/lupus) | Agente de Inteligência de Código

Agente LangGraph para explorar bases de código desconhecidas por meio de 17 ferramentas especializadas. Combina FAISS, BM25, Reciprocal Rank Fusion e reranking com CrossEncoder em um pipeline de recuperação híbrida, expõe uma camada FastAPI com streaming e oferece suporte a múltiplos provedores de LLM.

**Stack principal:** LangGraph · LangChain · LangSmith · FAISS · BM25 · CrossEncoder · FastAPI · SQLite

### [SRAG Agent](https://github.com/eduardo-ebdl/srag-agent) | Agente de Monitoramento Epidemiológico

Agente ReAct para monitoramento epidemiológico executado no Azure Databricks. Utiliza ferramentas SQL, geração de gráficos e busca web fundamentada sobre uma arquitetura Medallion governada com rastreamento no MLflow, Unity Catalog, Databricks Asset Bundles, gates de qualidade de dados, gestão de segredos e remoção de PII orientada à LGPD.

**Stack principal:** LangGraph · Llama 3 · Azure Databricks · dbt · Spark SQL · MLflow · Unity Catalog · Tavily

## Projeto adicional

### [Visual Study Tool](https://github.com/eduardo-ebdl/visual-study-tool) | Curadoria Semântica de Imagens

Busca de imagens em seis fontes com pipeline de ranking baseado em um ensemble CLIP, cache em SQLite, deduplicação de embeddings, interface Gradio, exportação em lotes e 164 testes unitários.

**Stack principal:** Python · Sentence Transformers · CLIP · Gradio · SQLite
