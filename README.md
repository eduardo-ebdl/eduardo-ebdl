### Featured

**[Lupus](https://github.com/eduardo-ebdl/lupus)** — AI Code Intelligence Agent.
A terminal agent for exploring unfamiliar codebases. Hybrid retrieval (FAISS + BM25 + CrossEncoder reranking) over 17 specialized tools orchestrated with LangGraph. Exposes a streaming FastAPI layer and swaps between LLM providers through a thin abstraction.

**[SRAG Agent](https://github.com/eduardo-ebdl/srag_agent)** — Epidemiological Monitoring Agent.
ReAct agent for epidemiological surveillance running on Azure Databricks. Full Medallion architecture (Bronze / Silver / Gold), MLflow tracing, Unity Catalog governance, and Databricks Asset Bundles for deployment. Built with LGPD compliance end-to-end — PII removal, data quality gates, secrets management.

**[Visual Study Tool](https://github.com/eduardo-ebdl/visual-study-tool)** — Semantic Image Curation.
Multi-source image search (DuckDuckGo, Unsplash, Pexels, Openverse, Wikimedia) with CLIP-based semantic ranking. SQLite caching for queries and embeddings, Gradio UI, batch export. A reference tool built for artists that happens to showcase embeddings, multi-source orchestration, and cache design.
